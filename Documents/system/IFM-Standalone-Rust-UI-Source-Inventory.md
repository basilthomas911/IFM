# IFM Standalone Rust UI Source Inventory

Date: 2026-10-18

This file lists the source files in the frontend areas examined for the [standalone Rust UI migration plan](IFM-Standalone-Rust-UI-Migration-Plan-v1.0.md). Build output directories are excluded. File counts include interfaces, helpers, partial classes and designer files; they are not counts of views or actor operations. Each link points to the existing source. No row claims that the standalone migration is implemented.

The operation registry required in phase 0 must follow reachable calls into shared helpers and nested contracts. Tests, generators, backend contract assemblies and native pricing code are dependencies described in the main plan, rather than exhaustively listed here.
