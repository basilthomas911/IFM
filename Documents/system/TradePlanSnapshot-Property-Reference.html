Iron Condor trade-plan snapshot: property reference

Updated 2026-10-17. Position.Legs is the authoritative leg collection. Each leg retains its latest accepted quote, last valid risk result (with original timestamps), economic pricing conventions and derived scenario evidence. Quote changes and pricing completions both reach the position owner. No simultaneous four-leg update is required.

Current spread/position values use retained marks. Greeks use last valid calculations. Scenario prices are repriced with the retained conventions and policy. Quote/risk age is retained separately. Missing inputs remain null with reasons. Legacy fields explicitly marked unavailable below are not implemented by this daily-risk calculator.

Historical snapshot 640 is unchanged. Missing historical risk inputs cannot be recreated from four marks alone. The new representation is populated by accepted enriched observations after deployment.
