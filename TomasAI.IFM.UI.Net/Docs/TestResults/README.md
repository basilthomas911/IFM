# Accepted UI system-test results

This folder retains reviewed, human-readable gate summaries that need to travel with the source. Each summary links its run ID, configuration, commit, gate decision, failed or blocked steps, and approved exceptions.

Raw screenshots, UI Automation trees, process/network captures, and logs belong under `TomasAI.IFM.UI.Net.SystemTests/TestResults/Runs/` and are ignored by Git. Do not copy secrets, credentials, API keys, or full connection strings into either location.
